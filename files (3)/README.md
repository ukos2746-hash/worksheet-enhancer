# Чёткий лист

Веб-приложение для улучшения качества рабочих листов, созданных через ChatGPT и другие нейросети.
Работает целиком в браузере — изображения никуда не отправляются.

**Попробовать:** после включения GitHub Pages приложение будет доступно по адресу
`https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`

## Возможности

- **Пакетная обработка** — загрузите сразу несколько листов, настройки применяются ко всем
- **Три режима**: «Для печати» (чёткий чёрный текст на белом, как скан), «Для экрана», «Деликатный»
- **Тонкая настройка**: увеличение до 3×, резкость, контраст, яркость, режим документа
- **Сравнение до/после** с перетаскиваемой шторкой
- **Экспорт в PDF**: все листы собираются в один многостраничный PDF (страницы A4, по центру, с полями)
- **Скачивание PNG** — по одному листу или все сразу

## Как это работает

Обработка выполняется на `<canvas>` чистым JavaScript, без библиотек:

- повышение резкости — нерезкое маскирование (свёртка 3×3)
- контраст и яркость — тоновая коррекция по каждому каналу
- режим документа — адаптивная бинаризация по локальному среднему (integral image),
  выравнивает неравномерный фон и делает текст чётким
- PDF генерируется вручную (минимальный PDF 1.4 со страницами-JPEG)

## Запуск локально

Просто откройте `index.html` в браузере. Сборка и сервер не нужны.
